# AI 圆桌 Android · 0.2.0 诊断版

第一阶段在真实手机验证 ChatGPT / DeepSeek。最终计划支持 ChatGPT、Gemini、Grok、DeepSeek、千问、豆包，元宝为可选参与者。目前只有前两个出现在可用参与者列表中，其余尚未适配。

## 0.2.0 本次修改与手机验证

针对空输入框显示语音按钮、输入后才出现发送按钮的界面，改为：等待控件稳定 → 确认唯一空输入框 → 填入一次 → 重新读取控件并核对输入 → 等待唯一可用发送按钮 → 尝试点击一次。准备过程最多 15 秒。轮询只等待和检查界面，不重试输入或发送。未知按钮仍暂停，不使用坐标猜测。

- 文字和无障碍描述分别匹配，修复相同标签拼接后无法匹配的问题。将明确标记为 hint 的占位文字与已有草稿区分。
- 页面未加载时在授权期限内等待；登录、验证提示、多输入框、已有草稿、切出目标应用或结果不确定时暂停。
- 返回圆桌会取消尚未完成的自动授权。退出编辑器只合并草稿，避免旧界面状态覆盖服务的新状态。
- 失败后可查看/复制诊断信息；也可点“只读页面诊断”，打开目标 App 等 2–3 秒后返回。它不输入或点击，只检查所选目标 App 的结构。诊断记录步骤、节点数、输入框/发送按钮数及少量控件类型与通用角色；不记录输入正文、聊天内容、账户或未知控件名称。
- 版本号提高到 0.2.0（versionCode 2），使用同一调试签名，可覆盖安装 0.1.0。

下一次真机验证：安装 0.2.0，确认服务仍开启，在 ChatGPT 手动选择“聊天”并打开空白聊天，清除“测试”等草稿。回圆桌停止旧讨论、新建仅 ChatGPT 的 1 轮讨论，将待发送内容改成“请只回复：收到测试。”，确认一次。留在 ChatGPT 最多 15 秒后返回圆桌。请反馈是否填入、是否发送，以及“复制诊断信息”的内容。若问题已发出，不要再次发送。

本次云环境验证仍不等于真实手机操作成功；尚未获得 0.2.0 真机结果。

## 当前功能

- 题目、参与者选择（固定 ChatGPT → DeepSeek 顺序，可只选一个）、1–5 轮；每轮所有所选参与者各发言一次。
- 开始、暂停、恢复、停止；每次转发前显示完整待发送内容并确认，可编辑长上下文（上限 12000 字符，不静默截断）。
- 本地私有 SharedPreferences JSON 保存当前讨论、题目、回复草稿及历史讨论，重开应用可恢复。停止后保留记录，开始新讨论会归档旧讨论。卸载清除记录；无云同步。
- 手动备用：确认复制问题 → 打开目标 App → 手动粘贴发送 → 等完整回答 → 复制回答 → 返回圆桌粘贴 → 确认完整后保存 → 下一位。
- 无障碍基本框架：按包名限制操作，先识别唯一空输入框并填入一次；重新读取界面，核对输入后等待明确“发送”按钮，只尝试点击一次。已有草稿、疑似登录/验证码、未知页面、点击失败、中断或超时均停止自动操作。不会自动重发。
- 显式请求读取后，尝试读取带明确助手语义标签的文本作为候选；不能证明是新消息或完整回复，必须人工检查。没有标签时使用手动复制。未实现 OCR 或滚动拼接。

**未在真实手机测试，不能声称 ChatGPT / DeepSeek 自动输入、发送、读取已经兼容。** 不同版本、语言和界面结构可能导致全部自动操作暂停；手动流程仍可用。回答不会被自动采纳，下一次发送也不会自动开始。

## 构建

建议 Android Studio，安装 Android SDK Platform 35、Build Tools 35.0.0。工程固定 AGP 8.7.3、Gradle 8.9；使用 JDK 17 或 21。最低 Android 8.0（API 26）。

1. Android Studio 打开仓库目录并同步 Gradle；或配置 `JAVA_HOME`、`ANDROID_HOME`，在未跟踪的 `local.properties` 写 `sdk.dir=/你的/Android/Sdk`。
2. macOS/Linux：`./gradlew assembleDebug testDebugUnitTest lintDebug`；Windows：`gradlew.bat assembleDebug testDebugUnitTest lintDebug`。
3. 输出：`app/build/outputs/apk/debug/app-debug.apk`，调试签名仅用于开发测试。

无 API 密钥或密码要求；无网络权限，圆桌自身不调用 AI API。目标 AI App 继续使用你自己的登录和网络。不要把密钥、账户或本地配置加入 Git。

## 安装和真机操作

- 开启手机开发者选项和 USB 调试，电脑安装 Android platform-tools；连接并在手机确认调试授权。
- `adb devices` 确认设备后执行 `adb install -r app/build/outputs/apk/debug/app-debug.apk`；也可将 APK 传到手机，允许所用文件管理器安装未知来源应用后安装。
- 打开圆桌；先选两个 App、1 轮，用无敏感信息的小问题跑通手动流程。
- 自动操作可选：点击无障碍设置，亲自启用“AI 圆桌辅助操作”。部分 Android 13+ 侧载安装需要在应用信息菜单允许受限设置（以系统实际选项为准）。无需 Root。
- 先在目标 App 手动登录并打开你期望的聊天，再回圆桌确认发送。每次授权 15 秒有效；手机保持解锁。圆桌不会新建或定位特定聊天。
- 返回圆桌查看结果。自动发送只代表尝试点击，不代表服务器收到。结果不确定时先检查目标 App，不要手动重复发送已发出的问题。
- 回复完成后可点“尝试读取”，目标 App 打开后返回圆桌查看候选；失败则手动复制。核对回答所属问题、来源、末尾和完整性，再确认保存。
- 暂停/停止可取消尚未执行的后续操作，但不能撤回已发送消息或终止目标 App 的生成。

## 真机验收清单

记录手机型号、Android 版本、目标 App 版本和语言。测试时避免敏感资料。

- 两个 App 各完成短问题输入、发送与长回答读取；核对无障碍候选与原文，不能把旧回答当成新回答。
- 选两轮，确认顺序为 ChatGPT → DeepSeek → ChatGPT → DeepSeek；每次发送都显示确认，无确认绝不发送。
- 生成过程中不提前采纳回复；读取失败、登录、验证码、弹窗、输入框已有草稿时停止自动操作，手动流程可继续。
- 连续点击确认、授权超时、切后台、旋转屏幕、进程终止、暂停/恢复，确认没有重复发送；重新打开后记录和草稿仍在。
- 停止后不能继续本次讨论；新讨论可查看旧记录。

## 实现限制

界面适配是保守的通用规则，包名暂定 `com.openai.chatgpt`、`com.deepseek.chat`。未支持不同包名、工作资料双开或多个设备。登录/验证码检测仅为启发式，无法涵盖所有页面。没有联网接口、截图、剪贴板后台读取或隐藏自动操作。系统无障碍权限只用于你主动授权的步骤，服务不扫描其他应用。剪贴板复制会覆盖原内容；转发会将上下文发给下一家 AI 服务。

当前记录无自动删除界面，可通过系统应用信息清除存储；清除会删除全部本地讨论。大量讨论的性能和其他 AI 适配属于后续工作。
